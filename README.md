# Projeto Base de API com Node.js

## 1. O que é este projeto?

Este é um projeto base, simplificado e criado com o objetivo didático de auxiliar alunos do Curso Técnico em Informática nos seus primeiros passos com desenvolvimento backend utilizando **Node.js**.  
A proposta é proporcionar um ponto de partida claro e funcional para que os estudantes compreendam os fundamentos da criação de uma API REST.

## 3. Quais são os pré-requisitos para instalação deste projeto?

Antes de começar, você vai precisar ter instalado na sua máquina os seguintes itens:

- **IDE de desenvolvimento** – Recomendado: [Visual Studio Code](https://code.visualstudio.com/)
- **[Node.js](https://nodejs.org/)**
- **[Git](https://git-scm.com/)**
- **Docker** (Opcional, para quem preferir rodar via containers)

## 4. Como instalar?

Siga os passos abaixo:

**Clonar o repositório**
git clone https://github.com/rmullo/primeira-api-nodejs.git

**Acessar a pasta do projeto**
cd primeira-api-node

**Instalar as dependências**
npm install -g nodemon
npm install

## 5. Como Utilizar?

## 5.1 Utilizando NPM.

No terminal executar o comando
npm run dev

## 5.2 Utilizando Docker.

No terminal executar o comando
docker compose up

Após iniciar o projeto, a API estará disponível localmente na seguinte URL:

http://localhost:3000/api/v1/first

Você pode testar acessando no navegador ou utilizando ferramentas como Postman ou Insomnia.
